# Kiosk demo

Statyczna prezentacja na pełny ekran: `index.html` + kilka plików JS/CSS, bez budowania, bez sieci (fonty w `fonts/`, ikony w `kiosk-icons.js`).

Parametry URL (nadpisują localStorage): `?p=N` produkt startowy (0–6) · `?s=N` scenariusz · `?speed=0.5|0.75|1|1.5|2` · `?robot=0` `?cat=0` `?hero=0` · `?theme=light`.

Klawisze: `1–3` scenariusz · `spacja` pauza · `←/→` scenariusz · `↑/↓` sekcja · `R` od nowa · `S` ustawienia · `F` pełny ekran.
